# Приложение для кинотеатра Премьер зал

Это компьютерное приложение для кинотеатра "Премьер Зал" было создано в рамках хакатона в университете. Оно предоставляет пользователям удобный интерфейс для просмотра информации о кинотеатре, выбора фильмов, расписания сеансов и покупки билетов.

На главном экране приложения — прокручивающаяся лента с фотографиями кинотеатра и текст с его основной информацией. Для навигации предложены три раздела: «Фильмы», «Расписание» и «Контакты».

<img width="2552" height="1821" alt="image" src="https://github.com/user-attachments/assets/fb727b9f-6795-4181-a7cd-d3772c029fe7" />

## 1. фильмы
В разделе "Фильмы" пользователь может ознакомиться со всеми фильмами, которые сейчас идут в кинотеатре. Для каждого фильма представлены название, постер и жанр.

<img width="2552" height="1824" alt="image" src="https://github.com/user-attachments/assets/f715d597-284f-4726-8267-76ae06600ed8" />

При нажатии на конкретный фильм открывается окно с афишей, где представлены название, жанр, возрастные ограничения и основная информация о фильме. 

<img width="2559" height="1822" alt="image" src="https://github.com/user-attachments/assets/16c72579-4ba1-48b6-8d01-08b4a2ed788e" />

## 2. Расписание

В разделе "Расписание" отображается актуальное расписание сеансов на выбранную дату.

<img width="2557" height="1821" alt="image" src="https://github.com/user-attachments/assets/a2afb8e4-afbe-4910-8982-81e6af815153" />

В разделе доступен выбор даты.

<img width="2553" height="1811" alt="image" src="https://github.com/user-attachments/assets/f479c2a4-a1be-4a17-a98f-86f731f4db10" />

При нажатии на время сеанса открывается схема зала для выбора мест, где фиолетовым цветом отмечены свободные места.

<img width="2035" height="1494" alt="image" src="https://github.com/user-attachments/assets/0ddc3dd5-25ee-4727-badb-5ffa5ff4a2e2" />

Выбранные места подсвечиваются серым цветом.

<img width="2046" height="1504" alt="image" src="https://github.com/user-attachments/assets/52a1cc4e-6043-4d33-bf3f-fadcc1620b02" />

После выбора мест и нажатия на кнопку "Купить" открывается окно для подтверждения покупки.

<img width="1393" height="858" alt="image" src="https://github.com/user-attachments/assets/470095e8-c2d6-45a4-8352-bed1ecc70242" />

После подтверждения покупки формируется электронный билет.

<img width="742" height="533" alt="image" src="https://github.com/user-attachments/assets/57bdd1d8-bc69-41a3-9c3f-a76ab3dc8e23" />

При нажатии на кнопку "Показать чек" открывается окно с кассовым чеком.

<img width="585" height="914" alt="image" src="https://github.com/user-attachments/assets/00c1a4be-fd27-4e1a-aa9b-5723f7644458" />
